# Focused-seat flash calibration

The Unassigned Seat MUI grid uses `data-field="seating"` for the link and `data-field="orderId"` for the booking number. A native seating click selects the row and can load a new map asynchronously. Clicking the order link or the map itself must not trigger the enhancement.

Etix's current public seat-rendering code uses `canvas.highlightOrderId` and module `81904`'s `jA` predicate to choose square versus circular booking-colour backgrounds. The active Fabric canvas is exposed by module `81161`'s `dX` getter. The native seat method is `drawAssignedSeatsBgShape`. These names were read from the site's public JavaScript bundles during the 22 November 2026 inspection.

`seat-focus-main.js` is a path-scoped MAIN-world reader. It captures the existing Webpack loader through a runtime callback and reads only the current canvas, the focused-booking predicate and viewport bounds. It never loads missing chunks, changes native drawing methods, changes selection state, calls render/transaction actions or exports customer/seat records. Only validated screen rectangles and canvas dimensions are returned through the DOM event channel.

`seat-focus.js` owns the independent `enhancements.flashFocusedSeats` setting. It observes normal seating-link clicks without cancelling them and waits up to 30 seconds for the correct native focus. Once matching seat geometry is ready, it scrolls the canvas into the centre of the viewport instantly, then draws non-interactive outlines for up to 30 seconds from that point. Scrolling happens only once per seating click, so polling never interrupts manual scrolling. Another normal click, form input/change/submit or Escape ends the highlight. A fresh seating click replaces it. Geometry is refreshed every 100 ms while active. Stale replies and modified clicks are ignored. The pulse uses one cycle per second, and reduced motion produces a static outline. A screen-reader status announces the highlighted seat count once. Root attributes `data-etix-seat-focus-state` and `data-etix-seat-focus-count` retain only the last display outcome and count for calibration; no booking/customer identifiers are recorded.

Fixture checks cover exact-booking matching during loading, scaled bounds, cancellation and stale responses, reduced motion, disabled settings, unavailable native modules, offscreen seats, detached rows and hidden pages. Future changes to Etix's native module exports fail closed: no inferred or whole-map pulse is substituted.

The live Chrome check on 22 November 2026 enabled the new enhancement, clicked a three-seat booking's seating link, and confirmed `state="finished"`, `detail="matched"` and `count="3"` on the page after the four-second highlight. The browser's inspection tools were closed afterwards. No seat-assignment or transaction controls were invoked.
